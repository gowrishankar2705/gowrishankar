## Features

- Responsive portfolio website
- Separate pages for key sections
- Shared styling and interactions
- Resume included in the repository
- Ready for GitHub Pages deployment

## Run Locally

Open `index.html` in a browser  
or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Deployment

This portfolio can be deployed easily using GitHub Pages or any static hosting platform.
